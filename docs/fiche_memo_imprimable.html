Bornes Type Comment les utiliser ?
E1 à E8 8 Entrées Digitales (0 ou 1) Brancher un bouton-poussoir, contact magnétique Reed ou phototransistor entre le trou du haut et le trou du bas.
EX et EY 2 Entrées Analogiques (0 à 1000) Brancher une photorésistance (lumière), une CTN (température) ou un potentiomètre (0 à 5 kΩ) entre haut et bas.
M1 à M4 4 Sorties Moteurs / Lampes (9V) Brancher un moteur, une ampoule, une LED ou une électrovanne entre le trou du haut et le trou du bas.
⚠️ 3 Précautions importantes :
1. Alimentation 9V : Prise ronde avec le + au centre (la LED rouge ⊥ doit s'allumer). Ne jamais brancher la prise ronde et les bornes 9V en même temps.
2. Sens des LEDs : Une LED a un sens (+ et -). Si elle ne s'allume pas sur M1..M4, inverse ses 2 fiches (haut ↔ bas) !
3. Port COM unique : Ferme toujours l'onglet TurboWarp avant d'utiliser Thonny (et inversement).

🐍 Programmer le 30 402 en Python (Thonny) & Défis

FICHE MÉMO CODERDOJO — VERSO (2/2)

1. Les Commandes Python dans Thonny

from ft30402 import Interface30402
import time

# 1. Connexion à l'interface (remplacer COM20 si besoin, ou laisser vide pour auto-détection)
ft = Interface30402("COM20")

# 2. Commander les 4 sorties M1 à M4
ft.moteur(1, "droite")             # Démarre M1 ("droite", "gauche", "frein", "arret")
ft.moteur(1, "gauche", duree=2.0)  # Tourne 2 secondes à gauche puis s'arrête
ft.lampe(2, True)                  # Allume la LED/lampe en M2 (False pour éteindre)
ft.arreter()                       # Coupe tous les moteurs (M1 à M4)

# 3. Lire les 8 entrées E1 à E8 et les 2 entrées analogiques EX, EY
if ft.entree(1):                   # Renvoie True si E1 est enfoncé, False sinon
    print("Capteur E1 touché !")

ft.attendre_entree(1, True)        # Met le programme en pause jusqu'à l'appui sur E1
valeur = ft.analog("EX")           # Renvoie la mesure entre 0 et 1000

2. Exemple Complet : Le Télérupteur (Bouton E1 → LED en M2)

from ft30402 import Interface30402
import time

ft = Interface30402("COM20")
allume = False

while True:
    ft.attendre_entree(1, True)    # Attend qu'on appuie sur E1
    allume = not allume            # Inverse l'état (True <-> False)
    ft.lampe(2, allume)            # Met à jour la LED sur M2
    ft.attendre_entree(1, False)   # Attend qu'on relâche E1
    time.sleep(0.05)

3. Les 4 Défis de l'Atelier CoderDojo

🟢 Défi 1 : Le Phare (15 min)

Branche un bouton sur E1 et une LED sur M2. Fais en sorte que la LED s'allume uniquement pendant qu'on appuie sur le bouton E1.

🟡 Défi 2 : Le Télérupteur (20 min)

Un premier clic sur E1 allume la LED en M2 ; elle reste allumée quand on lâche le bouton. Un second clic sur E1 l'éteint !

🟠 Défi 3 : Lampadaire Solaire (25 min)

Branche une photorésistance sur EX. Observe sa valeur entre 0 et 1000 et allume automatiquement M2 dès qu'il fait sombre (quand tu caches le capteur avec ta main).

🔴 Défi 4 : Tableau de Bord IHM (30 min)

Dans Scratch (ou en lançant 04_tableau_de_bord_ihm.py), crée un écran de contrôle qui affiche l'état des boutons en direct et arrête le moteur M1 dès qu'il touche le fin de course E1 !

4. Comprendre les Octets : Ce qui circule dans le câble RS-232

Lance exemples/03_espion_protocole_binaire.py dans Thonny ou coche le bloc (octet des entrées E8..E1 (en binaire)) dans Scratch : 20 fois par seconde, le PC envoie 2 octets et l'interface répond avec 1 octet où chaque bit (0 ou 1) représente un des 8 interrupteurs E8..E1 !
